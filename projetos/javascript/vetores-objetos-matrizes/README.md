# Vetores, Objetos e Matrizes em JavaScript

Esta pasta reúne a nova etapa de estudos em JavaScript, com exercícios sobre objetos, vetores de objetos e matrizes.

## Conteúdo

- `codigos/`: exercícios resolvidos em arquivos `.js`.
- `materiais/`: apresentações usadas como apoio para estudo e entrega.
- `index.html`: página de navegação desta etapa dentro do portfólio.

## Exercícios publicados

- `exercicio1.js`: objeto livro com título, autor e ano.
- `exercicio2.js`: vetor de produtos com nome, preço e estoque.
- `exercicio3.js`: cálculo do valor total do estoque.
- `exercicio4.js`: busca do produto mais caro.
- `exercicio5.js`: busca de aluno pelo nome.
- `exercicio6.js`: contagem de produtos com estoque baixo.
- `exercicio7.js`: alteração de preço de um produto.
- `exercicio8.js`: inclusão de desconto em todos os produtos.
- `exercicio1_matriz.js`: matriz 4x4 preenchida com zeros.
- `exercicio2_matriz.js`: média de temperaturas por cidade.
- `exercicio3_matriz.js`: maior temperatura registrada.
- `exercicio4_matriz.js`: verificação de matriz identidade.
- `exercicios_vetor_objetos.js`: lista reunida de exercícios sobre vetores de objetos.

## Como executar

Use Node.js para rodar um arquivo por vez:

```bash
node codigos/exercicio1.js
```

Os arquivos foram mantidos com acentuação em UTF-8 para evitar caracteres quebrados no GitHub.
