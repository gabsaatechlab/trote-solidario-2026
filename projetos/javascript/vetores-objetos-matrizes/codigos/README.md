# Códigos da Etapa

Esta pasta contém os exercícios JavaScript da etapa de vetores, objetos e matrizes.

## Vetores de objetos

- `exercicio1.js`: cria e exibe um objeto `livro`.
- `exercicio2.js`: percorre um vetor de produtos.
- `exercicio3.js`: calcula o valor total do estoque.
- `exercicio4.js`: encontra o produto mais caro.
- `exercicio5.js`: busca um aluno pelo nome.
- `exercicio6.js`: conta produtos com estoque abaixo de 5.
- `exercicio7.js`: altera o preço de um produto.
- `exercicio8.js`: adiciona desconto aos produtos.
- `exercicios_vetor_objetos.js`: versão reunida da lista.

## Matrizes

- `exercicio1_matriz.js`: cria uma matriz 4x4 com zeros.
- `exercicio2_matriz.js`: calcula médias em uma matriz de temperaturas.
- `exercicio3_matriz.js`: localiza a maior temperatura.
- `exercicio4_matriz.js`: verifica se a matriz é identidade.
