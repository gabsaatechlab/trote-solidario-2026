# Materiais de Apoio

Esta pasta guarda apresentações relacionadas à etapa de vetores, objetos e matrizes em JavaScript.

- `slides-vetores-javascript.pptx`: introdução e exercícios de vetores.
- `slides-vetor-de-objetos-javascript.pptx`: exercícios com objetos armazenados em vetores.
- `slides-matrizes-javascript.pptx`: exercícios e conceitos básicos de matrizes.

Os arquivos foram renomeados com nomes mais curtos e consistentes para facilitar a navegação no GitHub.
