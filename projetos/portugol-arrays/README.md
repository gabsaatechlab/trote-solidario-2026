# Portugol com Arrays

Esta pasta reúne exercícios recentes de Portugol voltados para arrays, repetição, busca, classificação e menus.

Os arquivos originais estavam em codificação Windows-1252. Nesta publicação, eles foram convertidos para UTF-8 para manter a acentuação correta no GitHub.

## Exercícios

- `01-media-de-notas-arrays.por`: cálculo de média, aprovação, recuperação ou reprovação.
- `02-maior-menor-valor-arrays.por`: leitura de valores, maior, menor e posições.
- `03-contagem-pares-impares-arrays.por`: contagem de pares, ímpares, positivos, negativos e zeros.
- `04-busca-em-array.por`: busca de nome dentro de um array.
- `05-gerenciador-notas-menu.por`: sistema de notas com menu, listagem, média, maior, menor e busca por posição.

## Objetivo

Mostrar evolução em lógica de programação usando estruturas mais próximas de problemas reais, com dados agrupados em arrays e interação por menu.
